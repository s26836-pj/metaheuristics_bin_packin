Problem Pakowania Pojemników (Bin Packing Problem)

Ten projekt skupia się na heurystycznych metodach rozwiązywania problemu pakowania pojemników. Problem ten polega na efektywnym umieszczaniu zestawu przedmiotów o różnych rozmiarach w minimalnej liczbie 
pojemników o określonej pojemności. Ze względu na złożoność obliczeniową znalezienia optymalnego rozwiązania dla dużych instancji, w tym repozytorium eksplorowane są różne algorytmy heurystyczne, które 
w akceptowalnym czasie dostarczają dobrych, choć niekoniecznie optymalnych rozwiązań.
